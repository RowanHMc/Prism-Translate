# PRISM-TRANSLATE
 Prism translate is a web page for translation of languages.

 ## Project Overview
 Communication has become difficult in the modern age where peopleare travelling to other countries either for education, tourism or vaccation purposes and hence diversity in languages. 
 Prism Translate is meanct to bridge this gap and help in language translation enabling easier communication among people.

 ## Features
 - Translate text between languages
 - Swap source and target languages
 - Text to speech pronunciation
 - Translation history
 - A charachter Counter
 - Responsive modern UI

 ## Technologies Used
 - HTML5
 - Tailwind CSS
 - JavaScript
 - VS Code
 
 ### API
 - Google Translate Public Endpoint

## Navigation in the page
1. Enter the source language.
2. Enter the target language.
3. Type the text you want translated.
4. Click **Translate**.
5. View the translated result.
6. Use:
   - 🔊 Pronounce
   - 📋 Copy
   - 🔄 Swap Languages
   - 🗑 Delete History
